baileys

Bot WhatsApp in Python con i decoratori. Port completo di Baileys (TypeScript) con un'API di alto livello sopra.

Python 3.10+asyncionessun browserstile decoratori
Non ufficiale. Nessun legame con WhatsApp o Meta. Automatizzare WhatsApp può portare al ban del numero: usalo a tuo rischio e non fare spam.

Avvio

pip install git+https://github.com/ChillatoOfficial/baileys.git

# con storage Redis
pip install "baileys[redis] @ git+https://github.com/ChillatoOfficial/baileys.git"
from baileys import Client, Message

client = Client('auth')                      # sessione salvata in ./auth

@client.command('ping')
async def ping(m: Message):
    await m.reply('pong 🏓')

client.run()

Scansiona il QR da WhatsApp → Dispositivi collegati → Collega un dispositivo. Al riavvio si riconnette da solo. Per il codice di pairing: Client('auth', pairing_phone='391234567890').

Eventi

I decoratori tipizzati chiamano l'handler una volta per elemento con un Event (dict con accesso via attributo; e.raw payload originale, e.client il client, await e.send(...) scrive su e.chat).

Gli eventi raw di Baileys funzionano ancora: @client.on('messages.upsert'), @client.on('creds.update').

Filtri e middleware

from baileys import filters

@client.message(filters.group & filters.regex(r'\bhello\b') & ~filters.from_me)
async def hello(m): ...

@client.use
async def log_and_ban(m, call_next):
    if m.sender in BANNED:
        return                       # stop: non gira nient'altro
    m.state['t0'] = time.monotonic() # dati condivisi con gli handler
    await call_next()

Filtri disponibili: text, from_me, group, private, media, quoted, media_type('image','video'), regex(...), equals(...), chat(...), sender(...). Combinabili con &, |, ~. Il middleware gira in ordine di registrazione; le eccezioni non fermano mai la connessione.

Coda di invio

Ogni client.send / m.reply passa da una coda: ordine per chat, spaziatura con jitter, retry con backoff sui guasti transitori (connessione chiusa, timeout, 503).

Client('auth', rate_limit={'per_chat': 1.0, 'global_': 0.3, 'jitter': 0.4, 'retries': 3})
Client('auth', rate_limit=False)            # disattiva
await client.send_now(jid, 'urgente')       # salta la spaziatura
await client.broadcast(jids, 'ciao a tutti')
Riduce la probabilità di sembrare un flood, non rende sicuri i messaggi massivi o non richiesti.

Tipi base

JID

str: '<n>@s.whatsapp.net' (telefono), '<id>@lid' (privacy ID), '<id>@g.us' (gruppo), '<id>@newsletter' (canale), status@broadcast. Helper: jid_decode, jid_encode, jid_normalized_user, are_jids_same_user, is_pn_user, is_lid_user, is_jid_group, is_jid_newsletter, S_WHATSAPP_NET.

MessageKey / WAMessage

class MessageKey(TypedDict, total=False):
    remoteJid: JID; id: str; fromMe: bool
    participant: JID; participantAlt: JID; remoteJidAlt: JID

class WAMessage(TypedDict, total=False):
    key: MessageKey; message: dict; messageTimestamp: int; pushName: str
    status: int          # 0 error, 1 pending, 2 sent, 3 delivered, 4 read, 5 played
    broadcast: bool; participant: JID

FAQ

ModuleNotFoundError: No module named 'baileys'

Installa nella stessa virtualenv con cui avvii il bot.

Il QR non appare

Il terminale è troppo stretto per disegnarlo, oppure usa pairing_phone=.

I miei messaggi non attivano i comandi

È voluto (ignore_from_me=True). Imposta ignore_from_me=False per testare con te stesso.

Lo sticker non si carica

Deve essere WebP: reply_sticker converte immagini, GIF e video (video richiede ffmpeg).

Come faccio logout?

await client.logout() oppure cancella la cartella/database di auth.
